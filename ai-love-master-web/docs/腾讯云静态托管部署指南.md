# 腾讯云静态托管部署指南

## 一、前提准备

1. **腾讯云账号**：https://cloud.tencent.com
2. **后端已部署**：前端需调用后端 API，请先把 Spring Boot 后端部署好，获得访问地址（如 `https://api.xxx.com`）

---

## 二、创建云开发环境

1. 打开 [腾讯云云开发控制台](https://console.cloud.tencent.com/tcb)
2. 点击「新建环境」
3. 环境名称：`ai-love-master`（自选）
4. 按提示完成创建，**记下环境 ID**（形如 `xxx-xxxxx`）

---

## 三、配置前端

### 1. 填写后端 API 地址

编辑项目根目录的 **`.env.production`**，把 `VITE_API_BASE_URL` 改成你的后端地址：

```
VITE_API_BASE_URL=https://你的后端域名
```

例如：`https://api.yourdomain.com` 或 `https://123.45.67.89:8080`

### 2. 填写云开发环境 ID

编辑 **`cloudbaserc.json`**，把 `envId` 改成你的环境 ID：

```json
{
  "envId": "你的环境ID"
}
```

---

## 四、安装 CloudBase CLI 并登录

```bash
npm install -g @cloudbase/cli
tcb login
```

按提示用浏览器扫码完成腾讯云登录。

---

## 五、构建并部署

```bash
cd ai-love-master-web
npm run deploy:cloudbase
```

或分步执行：

```bash
npm run build
tcb hosting:deploy ./dist -e 你的环境ID
```

---

## 六、配置 SPA 路由（重要）

部署完成后，必须设置 **错误文档**，否则刷新子路由会 404：

1. 打开 [云开发控制台](https://console.cloud.tencent.com/tcb) → 选择环境
2. 进入「静态网站托管」→「设置」
3. **索引文档**：`index.html`
4. **错误文档**：`index.html`，错误文档响应码：`200`

---

## 七、获取访问地址

在静态网站托管页面可看到默认访问地址，例如：

`https://你的环境ID.tcloudbaseapp.com/hosting/`

该地址即为前端访问入口。

---

## 八、后端 CORS 配置

后端需允许前端域名跨域，在 Spring Boot 中配置：

```java
// 允许腾讯云静态托管域名
.allowedOrigins("https://你的环境ID.tcloudbaseapp.com")
```

---

## 常见问题

| 问题 | 处理 |
|------|------|
| 刷新 404 | 检查错误文档是否设为 `index.html`，响应码是否为 200 |
| 接口请求失败 | 核对 `.env.production` 的 `VITE_API_BASE_URL`、后端 CORS |
| 部署命令报错 | 确认已执行 `tcb login` 且 `cloudbaserc.json` 中 `envId` 正确 |
