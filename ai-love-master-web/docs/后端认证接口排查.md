# 注册接口报错「No static resource api/auth/register」排查

## 错误含义
Spring Boot 收到 `/api/auth/register` 请求后，没有匹配到 `AuthController`，而是交给了静态资源处理器，最终返回「No static resource」。

---

## 1. 确认 AuthController 被扫描到

确保 `AuthController` 所在包在 Spring Boot 主类所在包或其子包下。

```java
// 主类：com.example.aimaster.AiMasterApplication
// AuthController：com.example.aimaster.controller.AuthController ✓ 正确
// AuthController：com.other.controller.AuthController ✗ 可能扫不到
```

若不在扫描范围，可显式指定：

```java
@SpringBootApplication(scanBasePackages = "com.example.aimaster")
public class AiMasterApplication { ... }
```

---

## 2. 检查静态资源配置

若存在 `WebMvcConfigurer` 且对 `/api` 做了资源映射，可能会覆盖 Controller。

**错误示例：**
```java
@Override
public void addResourceHandlers(ResourceHandlerRegistry registry) {
    registry.addResourceHandler("/**")  // 会匹配 /api/xxx
             .addResourceLocations("classpath:/static/");
}
```

**建议：** 排除 `/api`，或改为只映射静态资源路径，例如：

```java
registry.addResourceHandler("/static/**")
         .addResourceLocations("classpath:/static/");
```

---

## 3. 检查 Spring Security 放行

如果启用了 Spring Security，需放行认证相关接口：

```java
@Configuration
public class SecurityConfig {
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http.authorizeHttpRequests(auth -> auth
            .requestMatchers("/api/auth/**").permitAll()  // 登录注册无需认证
            .requestMatchers("/api/**").authenticated()   // 其他 API 需登录
            .anyRequest().permitAll()
        );
        return http.build();
    }
}
```

---

## 4. 检查 context-path

若设置了 `server.servlet.context-path`，实际路径会多一层前缀。

```yaml
# application.yml
server:
  servlet:
    context-path: /app
```

此时接口为：`/app/api/auth/register`，前端需配置：

```
VITE_API_BASE_URL=http://localhost:8080/app
```

---

## 5. 确认 RequestMapping 路径

Controller 示例：

```java
@RestController
@RequestMapping("/api/auth")
public class AuthController {
    @PostMapping("/register")
    public Result<Void> register(@Valid @RequestBody RegisterRequest req) { ... }
}
```

完整路径应为：`POST /api/auth/register`。

---

## 6. 快速验证

启动后端后，用 curl 测试：

```bash
curl -X POST http://localhost:8080/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"username":"test","password":"123456"}'
```

- 若返回 JSON，说明接口正常。
- 若仍返回 "No static resource"，多半是 1、2、3 的配置问题。
