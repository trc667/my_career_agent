# 腾讯云静态托管 - 控制台上传部署步骤

## 部署前必做

### 1. 填写后端 API 地址

编辑 **`.env.production`**，把占位符改成你的后端实际地址：

```
VITE_API_BASE_URL=https://你的后端域名或IP
```

⚠️ **必须先填正确**，否则构建后无法改，接口会全部失败。

### 2. 构建前端

```bash
cd ai-love-master-web
npm run build
```

生成 `dist/` 目录，里面是要上传的全部文件。

---

## 控制台上传步骤

### 1. 进入静态网站托管

打开 [腾讯云静态网站托管](https://console.cloud.tencent.com/tcb) 或你截图中的入口。

### 2. 点击「本地项目上传」

选择「本地项目上传」→「上传」或「选择文件夹」。

### 3. 上传 dist 目录内容

选择 `dist` **文件夹内的所有文件**（不是 dist 文件夹本身）：

- `index.html`（根目录）
- `assets/` 文件夹（包含 js、css）
- `vite.svg` 等静态资源

上传时确保 `index.html` 在根目录。

### 4. 配置 SPA 路由（重要）

在「高级配置」→「应用配置指南」或「设置」中：

| 配置项     | 填写值      |
|------------|-------------|
| 索引文档   | `index.html` |
| 错误文档   | `index.html` |
| 错误文档响应码 | `200`    |

否则刷新 `/login`、`/love-master` 等页面会 404。

### 5. 获取访问地址

部署成功后，在控制台查看访问地址，例如：

```
https://xxx.tcloudbaseapp.com
```

### 6. 配置后端 CORS

在后端环境变量中填写：

```
CORS_ALLOWED_ORIGINS=https://你的实际访问地址
```

（与上一步一致，不要加尾部斜杠和路径）

## 部署后自检

- [ ] 首页能打开
- [ ] 刷新 `/login` 不 404
- [ ] 登录接口能调通（Network 看请求）
- [ ] 无 CORS 报错

---

## 常见问题

| 问题           | 处理                                  |
|----------------|---------------------------------------|
| 刷新 404       | 检查「错误文档」是否为 index.html，响应码 200 |
| 接口失败 / CORS | 检查后端 CORS_ALLOWED_ORIGINS         |
| 白屏           | 检查 dist 是否完整、index.html 是否在根目录   |
